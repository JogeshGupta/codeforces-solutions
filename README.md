# Codeforces Solutions

My solutions to Codeforces problems, written in C++.

## How to run a solution

1. Clone the repo:
   
   git clone https://github.com/JogeshGupta/codeforces-solutions.git
   
2. Go into the folder:
   
   cd codeforces-solutions
   
3. Compile a file:
   
   g++ 69A.cpp -o 69A
   
4. Run it:
   
   .\69A.exe
